# Profile maintenance

README.md is the profile page. Edit the introduction there. Project card text lives in
scripts/build-assets.mjs (the `projects` list); edit it, then regenerate. Edit now.md for the
current reading note. Run these commands with Node 24 or later:

```sh
node --test
node scripts/build-assets.mjs
node scripts/update.mjs
```

The updater fetches the public RSS feed and public GitHub activity. GITHUB_TOKEN is
optional locally; Actions provides it automatically. Never put a token in a file.
A failed source preserves its existing README block and logs a warning (shown as an
annotation on the Actions run, which still succeeds). The workflow refreshes twice
a day, serializes runs, and commits only when content changes. Activity moves its
91-day window each day, so expect at least one commit a day.

The pixel-art banner, section strips, cards, technology grid, activity panel and footer are local
SVGs generated by scripts/build-assets.mjs, once per GitHub theme (assets/dark, assets/light).
README.md picks one with `<picture><source media="(prefers-color-scheme: dark)">`, which GitHub
resolves from the viewer's theme setting. Native text and links follow the GitHub theme.
GitHub scales images to the page width, so each wide image also has a `-mobile` version with
larger type, chosen below 600px by `(max-width: 600px) and (prefers-color-scheme: ...)`. Where a
`<source>` is ignored, the light desktop image is shown. Do not edit the SVGs by hand: `node --test`
fails if they differ from the generator, if README.md references a missing file, or if an asset
is no longer referenced. The generator throws if any text leaves its image or overlaps other text.

Type is outlined, not live text, so it looks the same on every device: JetBrains Mono for body
text and Silkscreen for pixel labels (both SIL OFL 1.1; see scripts/glyphs.LICENSE). The outlines
live in scripts/glyphs.mjs and were produced once by scripts/extract-glyphs.mjs, which needs
`npm i --no-save opentype.js@1.3.4` and the fonts' WOFF files; normal builds never need either.
Only ASCII plus · and — are available; adding another character means regenerating glyphs.mjs.

The 12 technology icons (scripts/icons) are vendored from Devicon and inlined into the technology
grid; their license is retained in scripts/icons/LICENSE. See https://github.com/devicons/devicon
for their source. Brand names and marks belong to their respective owners.

Activity data in data/activity.json comes from default-branch commit history for
all public, non-fork, non-archived repositories. It includes merge commits, excludes commits authored by
bots (Dependabot, the profile's own refresh commits) and is not a GitHub contribution
count. The panel uses 91 UTC dates ending on asOf, with daily counts. On refresh,
the updater fetches paginated history before replacing the snapshot; failed
sources keep the previous data. If a repository is renamed, made private or archived,
the repository drops out of the snapshot on the next refresh. "Recent
commits" lists each repository's latest non-bot, non-merge commit.
The workflow commits the snapshot and SVGs too.

To apply: copy these files into the w1tneess/w1tneess repository (including the
assets, scripts, tests and workflow), review the diff, then commit. Uploading only
the README will omit its header and updater. The profile changes when the files
reach the default branch. To revert, restore the previous commit.
