<h3 align="left">How <a href="https://github.com/w1tneess/advaita-website">advaita-website</a> works</h3>

<p>A personal portfolio and public notebook built with React 19 and Vite. Pages read through a content store that syncs with Supabase and falls back to seed data; an admin studio edits it.</p>

<a href="https://github.com/w1tneess/advaita-website"><picture><source media="(prefers-color-scheme: dark)" srcset="assets/arch-dark.svg"><img src="assets/arch-light.svg" width="100%" alt="Architecture of advaita-website: visitor to App Router, Public Layout and Public Pages; pages read a Content Provider and Content Store that syncs with Supabase Postgres and falls back to seed JSON; the site owner signs in to Admin Auth and Admin Panel, which imports data and checks sync health; a pre-render script reads the route config and a public copy of the database."></picture></a>
